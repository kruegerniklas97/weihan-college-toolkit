## Overview

Weihan's AI Tools is a student-oriented web dashboard that gathers common college planning needs into one workspace. Academic records, daily organization, and practical personal tools are available through the same interface, reducing the need to switch between multiple applications for coursework, routines, and habits.

As an installable PWA, the project follows an offline-first approach for situations where an internet connection is unavailable or unreliable. Supabase synchronization is available as an optional cloud feature for users working across devices, and Canvas LMS integration can bring assignment details into the same area as schedule and GPA information.

## Frequently Asked Questions

**How can I update the app?**  
Use the newest published build, or pull the latest repository changes when running the project from source.

**Will the dashboard work without an internet connection?**  
Yes. It is an offline-first PWA intended to remain usable without an active connection.

**Is Supabase required?**  
No. Supabase synchronization is optional, and the app can be used with local data alone.

**Why are my Canvas LMS assignments missing?**  
Review the Canvas synchronization setup and verify that the necessary application settings are configured properly.

**Where does the app keep its settings?**  
Settings are generally controlled through the application configuration and may also be stored in connected cloud services or local browser data, depending on how the app is configured.
